# AC-006 — ممیزی مستقل امنیت و معماری

- **مسئول:** Claude
- **نوع کار:** بازبینی فقط‌خواندنی، بدون تغییر کد
- **پایه بررسی:** main
- **مراجع:** PRهای ۶ و ۷؛ نقشه راه جاری

## هدف

بررسی مستقل امنیت، مرز شرکت/شعبه و صحت طرح F2 انجام بده. کار Z.ai را تکرار نکن و هیچ فایل، شاخه یا PR را تغییر نده.

## بخش اول: امنیت فعلی

در توابع has_role و can_edit، نحوه استفاده از SECURITY DEFINER، مجوز EXECUTE، search path، تعیین هویت و کنترل نقش را ارزیابی کن. مسیرهای کاربر خواننده، ویرایشگر و مدیر را بررسی و آزمون لازم برای محیط آزمایشی را پیشنهاد بده. آزمون حساب واقعی را انجام‌شده فرض نکن.

## بخش دوم: PR شماره ۶

پنج مورد زیر را مستقلاً ارزیابی کن:
1. حذف پیش‌نویس دارای Audit/Outbox؛
2. کنترل تعلق company_id و branch_id؛
3. Audit تکمیل مجاز فیلدهای سند Posted؛
4. برخورد شماره سندها و شکست نیمه‌اجرای Contract؛
5. جلوگیری از Rollback پس از گردش‌کار جدید.

بررسی کن آیا هر اصلاح پیشنهادی اصل تغییرناپذیری سند، سابقه حسابرسی یا جداسازی شرکت‌ها را تضعیف می‌کند یا نه.

## فرمت گزارش

برای هر یافته بنویس:
- شدت: مسدودکننده، بالا، متوسط یا پیشنهادی؛
- مسیر فایل و خط/نماد؛
- سناریوی بازتولید؛
- اثر بر امنیت، صحت حسابداری یا داده؛
- اصلاح حداقلی و آزمون اثبات‌کننده.

یافته قطعی را از فرض و ترجیح معماری جدا کن.

## محدودیت

کد تغییر نده، Pull Request نساز، Migration اجرا نکن و نتیجه آزمونی را که اجرا نشده گزارش نکن.

تحویل: گزارش مستقل فارسی، معیارهای پذیرش قبل از ادغام و فهرست تصمیم‌های لازم از مالک.
