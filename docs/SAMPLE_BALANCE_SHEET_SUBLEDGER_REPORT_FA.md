## کنترل‌های گزارش

گزارش production باید فقط اسنادی را جمع کند که `status IN ('posted', 'locked')` دارند. برای حساب‌های بدهکار، مانده معمولاً `debit - credit` و برای حساب‌های بستانکار، مانده معمولاً `credit - debit` نمایش داده می‌شود. این قاعده باید در query گزارش یا لایهٔ domain یکسان باشد و هر صفحه فرمول جداگانه نداشته باشد.

برای تولید نسخهٔ واقعی، query باید از `account_nodes` با یک recursive CTE استفاده کند تا جمع حساب‌های والد از فرزندان محاسبه شود. اتصال `journal_line_dimensions` نیز باید امکان فیلتر بر اساس طرف حساب، پروژه و مرکز هزینه را فراهم کند. قبل از ارائهٔ رسمی، دورهٔ مالی، واحد پول، rounding و وضعیت قفل‌شدن دوره باید به عنوان پارامتر گزارش مشخص شوند.
