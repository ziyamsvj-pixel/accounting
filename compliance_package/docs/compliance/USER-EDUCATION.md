# User Education Model

Compliance guidance is contextual and actionable.

Example:
این هزینه به فعالیت‌هایی با وضعیت مالیاتی متفاوت مرتبط است. مبنای تسهیم را مشخص کنید.

Actions:
- مشاهده مبنای مقرره
- مشاهده آموزش
- محاسبه تسهیم
- انتخاب روش
- ثبت تصمیم کاربر

Official law/standard, software interpretation, and control recommendation must be
visually distinguished.
